# Prashant Tinwal — Portfolio

Responsive portfolio made with HTML, CSS and JavaScript. Includes five project cards, project search, technology filter, dark mode, contact links and a chatbot interface.

## Deploy
1. Upload every file and the `api` folder to a GitHub repository.
2. Import the repository into Vercel and deploy.
3. For chatbot responses, add `OPENAI_API_KEY` in Vercel Project Settings → Environment Variables, then redeploy. Optionally set `OPENAI_MODEL`.
4. Never put API keys in public frontend files or GitHub.
